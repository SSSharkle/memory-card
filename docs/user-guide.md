# 用户指南

## 页面和学习流程

应用底部有“今日、牌组、统计、设置”四个入口。应用首次启动会创建 408 和政治分类，并放入少量演示笔记；这些分类和笔记都可在本机使用，不需要登录或联网。

在“今日”查看到期卡片和当天可学的新卡，点“开始复习”进入专注复习。到期卡优先，每日新卡上限默认 20 张，可在设置中改为 0–999 张。FSRS-6 安排短期学习步骤和后续复习；同一笔记的其他挖空卡在其中一张评分后会延至次日本地零点。

每张卡先显示正面。进入专注复习后，当前题目会保持为当前卡片；提交评分后再继续下一张。可以默想答案，也可在设置中打开输入框写下回忆；输入只在当前卡片临时显示，不保存、不自动判题。揭晓后对照参考答案，按自己的回忆情况选择“忘记、困难、记得、轻松”，按钮会显示预计间隔。评分用于安排下次出现时间，不是对学习者打分。

“牌组”中可以新建章节和笔记。列表首次显示最多 50 条笔记；还有更多结果时，点“加载更多（50 条）”继续查看。搜索会匹配标题、正文和标签；也可输入标签进行筛选。当前牌组范围包含其下级牌组，列表分页、搜索和筛选由本地数据库查询完成。删除笔记会同时删除它的卡片和评分历史，且无法撤销。统计页面显示当天及近 7 天、30 天的学习记录、章节进度和 FSRS 估计的回忆概率；该概率是模型估计，不代表考试正确率。

“设置”中可以调整每日新卡上限、目标保留率（70%–97%）、浅色/深色/跟随系统外观，并导入 Markdown 或管理备份。

## Markdown 文件格式

导入器读取 UTF-8 Markdown。可在文件开头添加 YAML 元数据，指定 `subject`、`deck` 和可选的 `tags`；没有元数据时会放入“未分类 / 收件箱”。每条笔记以 `##` 开始，并依次包含唯一的 `### 正面` 与 `### 背面`。标题、正面和背面均可使用 Markdown。

```markdown
---
subject: "408"
deck: "操作系统/进程管理"
tags: ["进程", "调度"]
---

## 进程是什么？

### 正面
操作系统中的进程可以怎样简要描述？

### 背面
进程是程序的一次执行过程。此句是格式演示用的简化示例。
```

更多基础卡、挖空卡和代码围栏示例见 [`samples/markdown/`](../samples/markdown/)。示例用于演示格式，不构成完整或经过系统审校的课程资料。

### 挖空卡

可在正面正文中写 `{{c1::答案}}`，也可添加提示，如 `{{c1::答案::提示}}`。同一个编号的空会一起隐藏；不同编号分别生成卡片。例如一条笔记含 `c1` 和 `c2`，会生成两张卡。挖空卡的背面可用于补充说明。

### 导入和重复项

1. 在“设置”选择“选择 Markdown 文件”。单个文件最大 8 MB。
2. 检查预览中的有效笔记、卡片数、重复项和错误；可以取消不想导入的笔记。
3. 点“导入所选”保存。格式有误的笔记不会列入可选项。

导入器依据科目、牌组、卡片类型、正面和背面识别重复项，比较前会去除首尾空白并统一 Unicode 规范形式；标题或标签单独变化不会产生新笔记。正面、背面或科目/牌组等识别内容发生变化时会按新笔记导入，原笔记和学习进度保留。错误格式演示见 [`samples/invalid/`](../samples/invalid/)。围栏中的 `##` 代码文本不会被当成笔记标题。

## 备份与恢复

设置页的“导出 ZIP 备份”会导出包含 `backup.json` 的版本化 ZIP 文件，其中有笔记、牌组、标签、卡片进度、评分历史和设置。请把导出的文件保存在自己管理的位置；选择恢复文件时请核对文件内容和时间。

恢复会完整替换应用当前数据和设置。应用会先在自己的私有目录保存恢复前的数据，再执行恢复；这个安全备份不会自动出现在文件选择器中。恢复后，在设置的备份区域可以导出最近一次恢复前安全备份，或回滚到该备份。回滚本身也会先保存当时的数据。建议在恢复前自行导出一份 ZIP 备份，并在恢复后检查内容。

学习数据保存在设备本地，没有云同步。卸载应用或清除应用数据会删除应用内数据和私有目录中的安全备份；单独导出的 ZIP 文件仍由你保存。备份可能包含个人学习内容，请妥善保管。

## 外观和显示

可选择浅色、深色或跟随系统。页面会显示 Markdown 的常用文本格式和代码块；图片不会显示，应用会以“[图片已忽略]”提示。

开源许可文本可在“设置”页面底部的应用信息区域点击“查看完整开源许可”查看。
