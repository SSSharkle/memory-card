# 考研闪卡 UI 实施规范

此规范对应已实现的 Kotlin / Jetpack Compose / Material 3 界面；所有内容保存在手机本地。

## 视觉基础

- 浅色：主色 `#245DD8`、页面背景 `#F6F8FC`、卡片底色 `#FFFFFF`、辅助色 `#1D796E`。
- 深色：主色 `#AFC6FF`、页面背景 `#11151E`、卡片底色 `#1B2230`。用户可选择跟随系统、浅色、深色。
- 使用系统无衬线中文字体及 Material 3 字体层级，正文通过系统字体缩放；卡片正文使用 28 sp 行高。
- 页面左右留白 20 dp、内容间隔 12–16 dp、卡片内边距 20 dp。主要操作按钮高 52 dp，评分按钮至少 64 dp。
- 导航和表单沿用 Material 3 默认触控目标与语义。点击操作同时使用文字标签，不只依赖颜色或图标。
- 图标为原创叠放闪卡：蓝色底、白色卡片和短横线；Android 8 使用自适应图标，Android 13 提供单色主题图标。

## 页面与操作

| 页面 | 主要内容 | 操作 |
|---|---|---|
| 今日 | 到期卡、可学新卡、今日评分、每日上限、下次到期 | 开始复习 |
| 牌组 | 408 / 政治层级、章节、笔记列表、内容搜索、标签筛选 | 新建、编辑、删除笔记；新增、改名、删除空牌组 |
| 统计 | 今日新学与复习评分、近 7 / 30 天逐日次数、预计回忆概率、章节状态比例 | 浏览 |
| 设置 | 新卡上限、目标保留率、临时输入回忆、主题、导入、备份、恢复、开源许可 | 系统文件选择器与预览确认 |

复习是独立专注页面：隐藏底部导航，右上角“结束”返回今日。当前卡片固定到用户评分或结束，其他卡片在复习中到期不会替换正在回忆的题目。

## 回忆与评分

1. 展示标题、卡片阶段和正面。挖空卡将当前编号的所有答案隐藏为 `【…】` 或提示；其他编号显示原答案。
2. 默认默想；设置打开“输入答案辅助回忆”后显示临时多行输入框。输入不会进入数据库，不进行 AI 或字符串自动判分。
3. 点击“揭晓答案”后显示参考答案及四个评分按钮：忘记、困难、记得、轻松。揭晓前不存在可评分按钮。
4. 每个评分按钮显示当前 FSRS 计算的下一间隔。写入期间所有评分按钮禁用；数据库同时检查卡片修订号与恢复世代，重复点击不能增加第二条评分。
5. 原卡片状态、评分历史与兄弟卡埋藏在同一事务内保存。新队列在成功评分后选择下一张，重启后从数据库重建。

## 内容与错误状态

- 首次启动带三条明确标注“示例”的基础笔记，生成四张卡；不将其包装为完整题库。
- 无任务时显示“当前任务已完成”和下一到期时间；无笔记时解释如何新建或导入。
- 笔记列表首批从 SQL 查询 50 条，显示总数与已加载数，底部“加载更多（50 条）”逐批扩大查询窗口。切换章节、搜索或标签时回到首批；筛选与计数均在 SQL 执行，按创建时间和 ID 降序稳定排列。
- Markdown 通过 CommonMark AST 转为原生文本，支持标题、强调、代码和列表。HTML 节点忽略，图片替换为提示，不执行 HTML、不访问远程图片、不打开链接。
- 导入先展示有效笔记数、生成卡片数、重复数、逐条行号错误；有效笔记可逐条勾选，确认后事务插入。变更后的内容生成新笔记，旧学习状态保留。
- 删除笔记必须确认，并明确会同时删除其卡片和历史。非空牌组删除报错，要求先处理子牌组和笔记。
- 恢复前明确展示备份数量与完整替换的后果。恢复期间全应用显示不可取消的操作对话框；安全备份保存成功后才替换数据，失败回滚。
- 设置页提供最近恢复前安全备份的导出与回滚入口。正常备份与导入通过 Android Storage Access Framework 使用用户选择的位置。
- 普通失败通过 Snackbar 显示；笔记编辑错误保留在当前表单；导入格式错误保留在预览中，避免丢失上下文。
