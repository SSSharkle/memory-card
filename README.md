# 考研闪卡

考研闪卡是一款面向考研复习的离线 Android 应用，使用 Kotlin、Jetpack Compose Material 3、Room 和 DataStore，支持 Android 8.0（API 26）及以上版本。学习数据保存在设备本地；应用不要求账号，也没有联网权限。

## 下载成品

- [v1.0.0 发布页](https://github.com/SSSharkle/memory-card/releases/tag/v1.0.0)：下载签名 APK、完整源码 ZIP 和 SHA-256 校验文件。
- 手机安装 APK 时，按系统提示允许当前文件管理器安装应用。
- 本版已在 Android 8.0 和 Android 15 模拟器验证，未进行实体手机测试；万条导入、分页搜索和跨设备备份恢复结果见下方测试报告。

签名私钥、本机 SDK、学习数据和构建缓存不随仓库公开。需要构建或延续原签名升级时，请阅读构建指南中的密钥说明。

## 功能

- **今日**：查看到期复习和当日可学新卡，按到期优先的顺序复习。
- **牌组**：管理章节、笔记与标签；列表按每页 50 条加载，可在当前牌组范围内搜索标题、正文和标签并按标签筛选。可以手动编辑卡片，也可以预览并导入 Markdown。
- **学习统计**：查看当天、近 7 天和近 30 天的评分次数、学习天数、章节进度，以及 FSRS 估计的回忆概率。回忆概率是模型估计，不代表考试正确率。
- **设置**：设置每日新卡上限和目标保留率，选择跟随系统、浅色或深色主题，开启临时输入答案辅助回忆，并导出或恢复完整 ZIP 备份。
- **复习**：先默想或临时输入答案，再揭晓参考答案；根据实际回忆情况选择“忘记 / 困难 / 记得 / 轻松”。输入内容不保存，也不会自动判题。
- 使用 FSRS-6 安排学习与复习。每日新卡默认上限 20；同一笔记的其他挖空卡会延后到次日本地零点。

应用首次启动时会建立 408（数据结构、计算机组成原理、操作系统、计算机网络）及政治（马原、毛中特、习思想、史纲、思修法治、形势与政策）分类，并附少量演示笔记。演示内容不是完整题库或经过系统审校的课程资料，用户可以创建自己的牌组和笔记。
